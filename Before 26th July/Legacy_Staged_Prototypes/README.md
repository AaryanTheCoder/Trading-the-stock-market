# Legacy staged prototypes

These are the original exploratory Stage 1-4 ML/RL scripts and
`SIMULATIONTEST.PY`. No serialized policies or comparable performance report
survived for these experiments, so the folder is explicitly labeled as
performance not recorded.

- `source/`: exploratory scripts.
- `data/cache/`: historical `.DS_Store` and Python bytecode cache files.

Several scripts download data, train immediately on import, or require optional
packages. Treat them as historical prototypes rather than maintained entry
points.
