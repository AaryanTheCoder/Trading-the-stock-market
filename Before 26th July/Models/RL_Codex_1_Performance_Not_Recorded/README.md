# RL Codex 1 — performance not recorded

RL Codex 1 is the single-AAPL PPO predecessor to RL Codex 2. Its training code,
saved policy, and 2025 simulation are preserved, but this repository does not
contain a comparable saved performance summary or trade spreadsheet.

- `source/`: AAPL PPO training code.
- `model/`: saved PPO policy.
- `simulations/`: intended untouched-2025 simulation.
- `data/cache/`: historical Python bytecode caches.

The simulation requires the optional `gym_trading_env` dependency.
